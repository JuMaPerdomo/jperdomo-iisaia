# Estructura sugerida para la presentación de 6 minutos

* **Minuto 1:** **Introducción y Problema.** Explica lo difícil que es para un líder de tecnología saber qué proyecto se va a demorar antes de que sea tarde.
* **Minuto 2:** **Usuarios y Solución.** Muestra a quién va dirigido y explica el concepto del Dashboard centralizado con alertas visuales.
* **Minuto 3-4:** **Explicación del MVP.** Detalla las 3 pantallas/vistas principales (Vista de Proyectos/Tarjetas, Formulario para actualizar estados y Panel de Métricas/Mapeo de riesgos).
* **Minuto 5:** **Stack y Arquitectura.** Explica cómo se conectan el Frontend en JS, el Backend en FastAPI y la Base de Datos SQLite.
* **Minuto 6:** **Cierre y Devolución.** Agradece y abre la palabra al docente para recibir feedback sobre el alcance.
